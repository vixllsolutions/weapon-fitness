WEAPON FITNESS 2 WEBSITE BUNDLE
================================

FILES
- index.html       Main one-page website
- styles.css       Layout, colours, responsive styling and animations
- script.js        Mobile navigation, reveal effects, training filters, gallery lightbox and WhatsApp enquiry form
- assets/          All uploaded gym photos and listing/review screenshots, directly inside this one folder

PREVIEW LOCALLY
1. Extract the ZIP archive.
2. Keep index.html, styles.css, script.js, and the assets folder together.
3. Open index.html in a modern browser. The site is static and does not require a build step.

DEPLOYMENT
Upload the contents of this folder to a static host such as GitHub Pages, Netlify, or your hosting provider. Keep filenames and the assets folder unchanged.

FEATURES
- Mobile-first responsive layout, accessible navigation, reduced-motion support and scroll-reveal animations.
- Training cards filter by strength, cardio and guided fitness.
- Gallery images open in a lightbox.
- Enquiry form opens WhatsApp with the visitor's chosen goal and optional phone number. This static site does not store or transmit form data except by the user opening WhatsApp.
- Clickable phone, WhatsApp and directions links.
